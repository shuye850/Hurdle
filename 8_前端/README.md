# 模块八：前端

模块八提供跨栏动作技术分析的本地网页界面，通过后端 API 完成视频上传、任务进度查询和分析结果展示。

## 当前功能

- 视频拖放与上传
- 分析阶段和百分比进度
- YOLO 栏架检测与 RTMPose 人体姿态的双路逐帧实时预览
- 历史任务列表
- 新建分析入口和单条历史记录删除
- 综合分、阶段分和单项技术评分
- 主要问题与规则版训练建议
- HTML、JSON、CSV 结果访问
- 桌面与移动端响应式布局

## 启动

macOS 可直接双击项目根目录的 `一键启动.command`。

或在项目根目录运行：

```bash
.venv_rtmpose/bin/python3.11 WEB.py
```

然后访问 `http://127.0.0.1:8000/`。

## 目录

- `dist/index.html`：页面结构
- `dist/assets/styles.css`：界面样式
- `dist/assets/app.js`：上传、进度和结果交互
